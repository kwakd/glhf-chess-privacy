# glhf-chess — privacy policy

The published privacy policy for the **glhf-chess** mobile game, served at
<https://kwakd.github.io/glhf-chess-privacy/>. This URL is the one given to Google Play.

**The source of truth is `docs/privacy-policy.md` in the game's own repository.** Edit it there
first, then update `index.html` here so the two cannot drift. The game's repo also holds
`docs/play-data-safety.md`, the matching Play Console answers — Google checks the policy and that
form against each other, so they change together.
